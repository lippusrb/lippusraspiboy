# Schema Elettrico Definitivo (Livello Produzione) - Console Custom Raspberry Pi Pico

Questo documento contiene l'architettura hardware completa e ottimizzata per la produzione. Include il modulo Joystick 5D e tutte le reti di disaccoppiamento necessarie per garantire stabilità assoluta.

---

## ⚡ 1. Alimentazione, Protezione e Livellamento (Power Block)

| Componente (Origine) | Destinazione / Collegamento | Funzione / Note |
| :--- | :--- | :--- |
| **Batteria 18650 (+)** | Schedina Ricarica (+) **E** Interruttore (Pin 1) | Nodo principale tensione positiva. |
| **Batteria 18650 (-)** | Schedina Ricarica (-) **E** Rete GND generale | Nodo principale massa. |
| **Interruttore (Pin 2)** | Diodo Schottky (Anodo) **E** Pin `VIN` PAM8302 | Amplificatore alimentato pre-diodo. |
| **Diodo Schottky (Catodo)** | Raspberry Pi Pico **VSYS (Pin 39)** | Protegge la batteria dai 5V dell'USB. |
| **Cond. Elettr. 10µF - 47µF (+)**| Pin **VSYS (Pin 39)** del Pico | Stabilizza l'ingresso al microcontrollore. |
| **Cond. Elettr. 100µF - 470µF (+)**| Pin **VIN** del PAM8302 | Fornisce i picchi di corrente per i bassi audio. |
| **Pico 3V3 OUT (Pin 36)** | `VCC` Display, `LED` Display, `VCC` SD | Linea logica 3.3V per le periferiche. |
| **Cond. Elettr. 10µF (+)** | Rete **3V3 OUT** (vicino al display) | Stabilizza i picchi di assorbimento del TFT. |
| **Cond. Ceramico 100nF (104)** | In parallelo al condensatore da 10µF | Filtra il rumore ad alta frequenza del bus SPI. |
| **Tutti i poli negativi/GND** | Pin 38 Pico, GND Display, GND SD, GND PAM8302 | **Rete GND generale:** Tutte le masse unite. |

*(Nota: Tutti i poli negativi dei condensatori elettrolitici vanno alla Rete GND generale).*

## 🕹️ 3. Input: Modulo Joystick 5D e Pulsanti

Tutti i contatti portano a massa (GND). Il pull-up viene attivato via software.

| Comando | Pin Modulo/Pulsante | Pin Raspberry Pi Pico |
| :--- | :--- | :--- |
| **Joystick - Su** | Pin `UP` | GP2 (Pin 4) |
| **Joystick - Giù** | Pin `DOWN` | GP3 (Pin 5) |
| **Joystick - Sinistra**| Pin `LEFT` | GP4 (Pin 6) |
| **Joystick - Destra** | Pin `RIGHT` | GP5 (Pin 7) |
| **Joystick - Centro** | Pin `MID` / `SET` | GP0 (Pin 1) - *Tasto Extra* |
| **Joystick - Massa** | Pin `COM` / `GND` | Rete GND generale |
| **A (Azione 1)** | Un piedino del pulsante | GP6 (Pin 9) |
| **B (Azione 2)** | Un piedino del pulsante | GP7 (Pin 10) |
| **X (Azione 3)** | Un piedino del pulsante | GP8 (Pin 11) |
| **Y (Azione 4)** | Un piedino del pulsante | GP9 (Pin 12) |
| **Start** | Un piedino del pulsante | GP21 (Pin 27) |
| **Select** | Un piedino del pulsante | GP22 (Pin 29) |

*(Nota: il secondo piedino di tutti i pulsanti singoli A, B, X, Y, Start e Select va alla Rete GND generale).*

## 🎵 6. Audio Subsystem (Filtro, Controllo e Amplificazione)

1. **Sorgente PWM:** Collega il pin **GP20 (Pin 26)** a una **Resistenza (220Ω)**.
2. **Filtro RC Passa-Basso:** All'uscita della resistenza, collega un **Condensatore Ceramico 100nF (104)**; collega l'altro piedino del condensatore a **GND**.
3. **Ingresso Volume:** Dal nodo tra resistenza e condensatore, entra nel **Pin 1** del potenziometro rotativo da 10k.
4. **Massa Volume:** Collega il **Pin 3** del potenziometro a **GND**.
5. **Uscita Volume:** Collega il **Pin 2** (cursore centrale) all'ingresso **A+** del modulo PAM8302.
6. **Massa Audio:** Collega l'ingresso **A-** del PAM8302 a **GND**.
7. **Speaker:** Collega i pin **OUT+** e **OUT-** del PAM8302 ai poli del mini altoparlante da 1W.
